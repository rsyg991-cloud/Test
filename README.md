# Balbal — from your first words to the IELTS band you need

Balbal is a full-stack English learning platform that takes a learner from **any level, even absolute beginner (A0)**, to the **IELTS band they need**, across all four skills — **Reading, Listening, Writing and Speaking** — in **seven stages**, on a plan of **1, 2, 3, 4, 6, 9 or 12 months**.

## The learner journey

1. **Find your level** — beginners answer one question ("How much English do you know?") and start at Stage 1, 2 or 3 straight away. Learners at B1 or above take the **placement test (~15 min)**: grammar, reading, listening, a short writing task and a speaking question → a starting band for each skill and a recommended stage (`content/stageList.ts`).
2. **Choose a plan** — 1 month (Sprint) · 2 (Accelerate) · 3 (Balanced) · 4 (Steady Climb) · 6 (Deep Growth) · 9 (Foundation Builder) · 12 (Zero to IELTS). The plan is recommended from the band gap and the exam date. It warns if it would end after the exam, and says honestly when it is too tight for the learner's path ("about 3 lessons every day").
3. **Climb seven stages** — the path runs from the learner's start stage to the stage that reaches their target band (`endStageFor`), so a Band 6.0 target ends at Stage 5 and a Band 7.5+ target runs to Exam Mastery:

   | Stage | Camp | Level | Focus |
   |---|---|---|---|
   | 1 First Words | Trailhead | A0 → A1 | Alphabet and spelling, numbers and times, simple texts, first sentences, personal questions |
   | 2 Everyday English | Foothills | A1 → A2 | Comparisons, past and future, everyday calls and forms, first emails, a 45-second talk |
   | 3 Ready for IELTS | Approach | A2 → B1 | First T/F/NG, Part 1–2 listening, first chart and essay, first Part 2 and Part 3 |
   | 4 Foundation | Base Camp | B1 → B1+ | Test format, skim/scan, Listening Parts 1–2, Task 1 basics, Part 1 fluency |
   | 5 Development | The Ridge | B1+ → B2 | T/F/NG, headings, Part 3 discussions, full Task 2 essays, 2-minute Part 2 |
   | 6 Advanced | High Camp | B2 → C1 | Inference, writer's views, Part 4 lectures, argument depth, abstract Part 3 |
   | 7 Exam Mastery | The Summit | C1 | Timed passages, distractors, Band 8 language, full mock |

   Each stage has 3 units × 4 skills (84 lessons in total) and ends with a **checkpoint test** across all four skills that unlocks the next stage.

   **Foundation stages (1–3)** explain every strategy in Arabic beside the English (right-to-left, Noto Kufi Arabic). Stages 1–2 also give the Arabic meaning of every word and an Arabic explanation for every answer; Stage 3 keeps only the strategy summaries, and the Arabic is gone from Stage 4. Listening in these stages starts slower (0.8–0.95×). Foundation lesson ids start with `f1-`…`f3-`; the IELTS stages keep their original `s1-`…`s4-` ids so saved progress stays valid (the `seven_stages` migration shifts stored stage numbers by three).
4. **Every lesson** = a short strategy ("Skill builder") → key vocabulary flip-cards → a real IELTS-style task → instant feedback.

## Brand

**Balbal (بلبل)** — the bulbul, the bird that sings: Balbal is about learning to speak. The "Score Sheet" identity is built from the exam itself: the answer sheet, the filled answer bubble and the highlighter that marks what matters. The mark joins the two ideas: a bulbul whose body is the filled answer bubble, with a crest, a beak and a tail like the tail of a speech bubble, on a highlighter tile. The wordmark is "Balbal" (the second "bal" marked by the highlighter) beside "بلبل"; on phones the header shows the mark and "Balbal" only.

- **Colours** are tokens in `app/globals.css` (light and dark): paper, sheet, ink, one action colour (ink in light, the highlighter yellow in dark), the highlighter `#FFE14D`, sheet red for wrong answers, a green for correct ones, and one colour per skill.
- **Type**: Archivo Black for headlines, Public Sans for text, JetBrains Mono for every band, score, timer and question number (`.num`), Noto Kufi Arabic for Arabic (`.ar`).
- **Logo** files are in `public/brand/` (lockup, on-dark, one-colour, mark); the site's `<Logo>` uses the same outlined paths (`components/logo-paths.ts`), and `app/icon.svg`, `app/apple-icon.tsx` and `app/opengraph-image.tsx` are built from the mark.
- One highlighted word per headline (`.hl`), tight corners (6 / 10 / 16 px), borders rather than shadows.
- The logo files are generated by a fontTools + HarfBuzz script (the Arabic is shaped before outlining, so the letters join correctly).
- The platform was called BandUp before. A few invisible identifiers keep that name on purpose, because renaming them would break things: the session cookie `bandup_session` (renaming logs everyone out), the browser keys `bandup:draft:…` and `bandup:mock:…` (saved drafts and in-progress tests), and the n8n webhook header `X-BandUp-Secret` with the example path `bandup-evaluate` (existing n8n workflows check them).

## What keeps learners going

- **Today screen** with one clear session, a daily-minutes goal ring and a "Start" button.
- **Streaks** with a weekly strip, streak freezes (earned every 7 days), XP.
- **Band tracker**: per-skill estimated band over time against the target line.
- **Journey map** showing exactly where you are on the mountain.
- **Spaced-repetition vocabulary deck** (SM-2) filled automatically from lessons.
- **AI Conversations** (20 role-plays, 5 per IELTS stage) — see below.
- **AI practice drills** (24 extra Writing/Speaking prompts) to fill daily minutes on longer plans.
- **No-guilt catch-up**: if you fall behind, one tap re-paces the plan so today is a fresh start.
- Celebrations (confetti, XP, band) after lessons and checkpoints.

## AI Conversations — learn first, then talk with ChatGPT

20 speaking role-plays (5 per IELTS stage, Stages 4–7, from "Meeting a New Classmate" to full mock speaking tests and C1 discussions) in `content/conversations/`. Each one has five steps:

1. **Learn** — goals, 5 key phrases with examples, a grammar focus, vocabulary flip-cards.
2. **Listen** — a model dialogue played with two voices, with transcript.
3. **Check** — 3 quick questions; 2/3 unlocks the conversation.
4. **Talk** — a ready-made ChatGPT prompt (`lib/conversation/prompt.ts`) that sets the role, the learner's level, the target phrases and missions, keeps ChatGPT's replies short, avoids mid-conversation corrections and ends with feedback when the learner says "END". One tap copies it; another opens ChatGPT (voice mode recommended).
5. **Reflect** — a self-check list, then paste the conversation back for Balbal feedback on the learner's turns (fluency & interaction, vocabulary, grammar, use of target language). Completing adds XP, streak, vocabulary and a speaking band estimate.

They live on the Practice page, and the dashboard suggests one each day.

## Full IELTS mock test & official format

- **Full mock test** (`/mock/original-test-1`): a complete IELTS Academic test written for Balbal in the official format — 4 listening parts (40 questions, each recording plays once, map labelling), 3 reading passages (40 questions, ≈2,350 words, 60 minutes), Writing Task 1 + Task 2 (60 minutes, Task 2 counts double) and a 3-part speaking test. Timers auto-submit, progress survives a reload, answers are graded on the server (never sent to the browser), and results show bands from the published conversion tables, accuracy by question type and a full answer review.
- **All official question types**: multiple choice (one / choose TWO), True/False/Not Given, Yes/No/Not Given, matching (headings, features, sentence endings), note/form/summary completion with word limits, summary with a word box, map/diagram labelling, short answer (`lib/mock/`).
- **Licensed past papers**: the engine can load authentic tests (e.g. Cambridge IELTS) with real audio once you have a licence — see **[docs/licensed-tests.md](docs/licensed-tests.md)**. `npm run validate:tests` checks every test file. Licensed files are git-ignored.
- **Resources page** (`/resources`): links to the official free practice tests (British Council, IDP, IELTS.org) and the Cambridge books, with a warning about pirated "past paper" sites.

The 48 lessons and stage checkpoints are original practice material, shorter than the real test by design (they teach one skill at a time). From **Stage 3** on, every Reading and Listening lesson and checkpoint uses the **official question types and instructions** (Yes/No/Not Given, choose TWO, matching information/headings/features/sentence endings, completion with word limits, summary word boxes), graded by the same engine as the full mock test.

## AI evaluation: n8n webhook, Claude or demo

All evaluation goes through one request shape with three interchangeable providers (`lib/ai/evaluate.ts`), chosen with `AI_PROVIDER` or automatically:

- **n8n webhook** (`N8N_EVAL_WEBHOOK_URL`, optional `N8N_WEBHOOK_SECRET`) — connect any model, including free ones. Full request/response contract and workflow steps: **[docs/n8n.md](docs/n8n.md)**.
- **Claude API** (`ANTHROPIC_API_KEY`).
- **Offline demo evaluator** — used when neither is configured, clearly labelled.

### Claude provider details

Writing and Speaking are graded by Claude (`lib/ai/evaluate.ts`) with structured output: a band per official IELTS criterion, strengths, the 3 highest-impact next steps, line-by-line corrections, and the learner's **own answer rewritten one band higher**.

- Speaking uses the browser's microphone (`MediaRecorder`) plus live speech-to-text (Web Speech API; Chrome/Edge). The transcript, speaking time and rate are sent for grading; pronunciation is clearly labelled as an estimate. Other browsers fall back to typing what was said.
- Listening audio is generated in the browser with speech synthesis (two voices, adjustable speed, optional "exam mode: play once").
- The API key stays on the server. Requests use the server-side refusal fallback, and each learner has a daily evaluation limit (`AI_DAILY_LIMIT`).
- With no evaluator configured (or with `AI_MOCK=1`) the **offline demo evaluator** gives a rough heuristic estimate, clearly labelled, so the whole app can be tried locally.

## Tech

Next.js 15 (App Router, Server Actions) · TypeScript · Tailwind CSS 4 · Prisma + PostgreSQL (Neon in production) · `@anthropic-ai/sdk` · email/password auth with hashed session tokens in httpOnly cookies · Vitest.

```
app/                    pages (landing, auth, onboarding, dashboard, journey, learn, checkpoint, practice, vocab, progress, plan)
app/actions/            server actions (auth, onboarding, lessons/checkpoints, vocab & plan)
app/api/evaluate/       AI grading endpoint
components/             UI, journey map, charts, lesson player, task views (reading/listening/writing/speaking)
content/                the curriculum: 7 stages, 84 lessons, 7 checkpoints, placement test, practice prompts
content/stageList.ts    client-safe stage summary, target-stage and placement rules
content/conversations/  20 AI-conversation role-plays (learn-first material + role-play setup)
lib/plan/scheduler.ts   plan pacing, review days, catch-up, plan recommendation
lib/scoring.ts          answer checking, IELTS band rounding, band estimates
lib/srs.ts              spaced repetition
lib/ai/                 evaluator providers (n8n webhook, Claude, offline demo), schema, response parsing
lib/conversation/       ChatGPT role-play prompt builder
lib/mock/               full-test schema, grading rules, band tables, validator, test registry
content/mock/           full mock tests (original); licensed tests go in MOCK_TESTS_DIR
docs/n8n.md             n8n integration guide
docs/licensed-tests.md  how to license and import authentic IELTS tests
prisma/                 schema + demo seed
```

## Run it

```bash
npm install
cp .env.example .env        # point DATABASE_URL(_UNPOOLED) at any Postgres; set N8N_EVAL_WEBHOOK_URL for real AI grading
npm run setup               # run migrations and seed a demo learner
npm run dev                 # http://localhost:3000
```

Demo learner: `demo@balbal.app` / `demo12345` (3 weeks of history, streak and bands).

Checks:

```bash
npm run typecheck
npm test                    # scheduler, scoring, SRS, curriculum & conversation integrity, prompt builder, webhook parsing, mock grading & validator
npm run validate:tests      # validate all full tests (built-in + licensed)
npm run build
BASE_URL=http://localhost:3000 npm run e2e   # browser smoke test: register → placement → plan → lesson → AI conversation → full mock test → dashboard
```

**Deploying**: Vercel + Neon, every push deploys automatically — step-by-step in **[docs/deploy.md](docs/deploy.md)**.
